ABSOLUTE DEFENSE — Android APK (версия 1.0)

Это исходный Android-проект, а не готовый APK. Игра запускается офлайн внутри Android WebView.

КАК СОБРАТЬ APK ЧЕРЕЗ GITHUB С ТЕЛЕФОНА:
1. Создайте НОВЫЙ публичный репозиторий, например absolute-defense-android.
2. Загрузите СОДЕРЖИМОЕ этого ZIP в корень репозитория (не сам ZIP).
   Важно сохранить папки .github/workflows, app/src/main/assets и другие.
   Для загрузки целой структуры папок с телефона удобнее использовать
   GitHub через браузер в режиме «Версия для ПК» или загрузить файлы через ПК.
3. Откройте Actions → Build ABSOLUTE DEFENSE APK → Run workflow.
   Также сборка автоматически запускается после загрузки файлов в main.
4. Дождитесь зелёной галочки, откройте запуск и скачайте артефакт
   ABSOLUTE-DEFENSE-APK в разделе Artifacts.
5. Распакуйте скачанный ZIP, установите app-debug.apk на Android.
   Разрешайте установку только для файлов, которые собрали сами.

ПРИМЕЧАНИЯ:
- Приложение полноэкранное, вертикальное и работает без интернета.
- Рекорд сохраняется локально на устройстве (WebView localStorage).
- Это debug APK для личного тестирования, не релиз для Google Play.
- Для обновления игры меняйте файлы в app/src/main/assets/.
- Исходные файлы игры сохранены без изменений.
